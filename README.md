# Precision Machinist Math

Precision Machinist Math is an offline Android calculator and reference app designed for machinists, toolmakers, inspectors, and other precision manufacturing work.

## Included Tools

- Three-Pin Bore Calculator
- Thread Calculator — Inch and Metric
- Right Triangle Calculator
- Sine Bar Calculator
- Metric Fits Reference
- Countersink Reference
- Hardness Conversion Reference

## Features

- Works completely offline
- Inch and metric calculations
- Shop-friendly precision and formatting
- Three-pin combination finder for practical pin selection
- Simple interface designed for use at the machine or inspection bench
- No account or internet connection required for calculations

## Version

Current stable release: **v1.0.0**

The Android APK is available under **Releases**.

## Important

Precision Machinist Math is intended as a shop calculation and reference aid. Always verify critical dimensions and requirements against the applicable drawing, specification, or standard.
